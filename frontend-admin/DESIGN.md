# Admin 界面规范

本后台服务于平台管理员，优先保证信息层次、可读性和操作反馈。蓝色主色、深色导航、浅灰画布与白色面板构成固定视觉基础。

## 样式与组件

- 颜色、圆角和控件高度使用 `src/style.css` 中的 `--admin-*` 变量。需要修改主题时统一修改变量，不在每个页面单独覆盖。
- 页面标题使用 21–23px，面板标题 16px，表格正文 12–13px，说明文字 11–12px。长文本允许换行，产品标题在列表中最多展示三行，完整内容保留在标题提示中。
- 页面边距为桌面 24–32px、手机 16–20px；常规控件高度 40px。主操作使用 `.primary`，次要操作使用 `.secondary`。
- 每个操作区保留清楚的操作层级，避免每一行都出现同等醒目的蓝色实心按钮。
- 模型页样式放在两份模型样式文件中，数据页样式放在 `DataManagement.vue` 中；移除失效样式，不持续叠加覆盖。
- 弹窗复用 `dialog-focus.ts`，标明 `role="dialog"`、`aria-modal="true"` 与可访问标题。打开时聚焦表单，支持 Tab 循环、Escape 关闭与关闭后焦点回位；保存期间禁止关闭。
- 需要校验的输入必须放在实际的 `<form>` 中，配合 `required`、输入类型和范围约束。不得仅在普通容器中设置这些属性后声称具备提交校验。

## 响应式与状态

- 手机必须保留四个文字导航入口。禁止通过隐藏导航或将字号设为零来解决空间问题。
- 模型列表在中屏和手机重排；业务数据表可在面板内横向滚动，页面本身不得被撑宽。
- 加载中、空结果、失败、保存成功和禁用状态都要有明确表达。尚未加载的数据不能被展示为已确认的零值或正常状态。
- 刷新提供进行中状态，禁止重复提交；网络加载错误保留会话并提供重试，认证失效才退出。
- 对尚未保存的配置，不提前更新已保存状态；保存失败保持界面与服务端一致。

## 交付检查

使用真实浏览器检查默认桌面、960px 中屏与390px手机宽度；检查导航、筛选与重置、弹窗键盘操作、长标题和数据表滚动。保留截图与验证限制。构建通过不能替代界面验证。

构建入口为 `npm run build`；TypeScript 使用 `noEmit`，由 Vite 输出 `dist`，避免生成或提交旁边的 `.js` 与编译缓存变更。

本机容器操作使用项目根目录的 `./deploy/local.sh`；腾讯云使用 `./deploy/tencent.sh`。镜像仓库超时时可对已有本机测试容器复制构建产物做临时预览，但必须明确这不等于完成镜像重建或云端部署。
