# Haitoro 项目图标

原图由用户选定，采用紫色面裙子镂空、橙色面原缺口的魔方设计。

- `haitoro-icon-source.png`：未经修改的原始图片。
- `haitoro-icon-transparent.png`：移除外侧浅色背景并裁掉外围留白的透明母版。
- 两个前端的 `public/brand-icon.png`、`public/favicon.png`、`public/apple-touch-icon.png` 分别为 512、32、180 像素，均由同一母版等比导出。

透明背景通过内置 ImageGen 处理，使用的编辑提示要求：仅移除紫色圆角底之外的浅色背景，裁剪至紫色底的边界，圆角外透明；保留紫色底、顶部菱形、紫色面裙子镂空、橙色面原缺口、内部比例与配色，不添加元素。随后按透明像素边界裁剪并使用 Lanczos3 缩放导出。

页面图标使用本地静态资源路径，不依赖生成目录或聊天附件。更新图标时同步替换两个前端的三份导出资源。
