# 公司公开货盘：实现与运行说明

本功能按公司隔离，生成 TikTok 导入表格；实际商品链接由 TikTok 上架流程产生。素材图片统一保存或复用公开 R2 文件，最终 Excel 写入私有 R2。

## 账号、权限与入口

- 内部导航在产品库下方新增公开货盘；货盘用户默认进入货盘模板，可使用公开模板及自己的策略、任务，不能查看货盘素材。前端隐藏货盘素材标签且不请求素材列表，后端对素材列表、使用记录、上架和检查接口统一拒绝货盘用户访问；内部角色保留原有权限与公司隔离。
- 新增 supply_user 外部角色；旧业务接口明确限制为内部角色。
- 货盘管理权限附加到成员、组长，不替换原角色。可管理素材上架、模板公开、查看公司用户/任务/统计及审计下载，不能创建、编辑、停用、恢复、续期用户。
- 公司管理员维护代理、货盘用户、管理授权、AI配置。代理只有名称，没有登录或邀请注册。
- 创建账号必须选择本公司代理，默认12个月。从创建时刻按香港自然月计算，目标月份没有对应日时取月底，存储UTC。
- 未到期续期从原期限延长，已到期从当前时间延长。续期不恢复停用，恢复不延长期限。
- 到期或停用禁止登录、访问、下载，取消未完成任务；取消任务不自动恢复。历史任务代理归属不随账号修改变化。

## 公开素材、策略与快照

模板公开与素材上架独立，新增素材不自动上架。模板公开前校验物流参数、描述和25–220字符英文兜底基础标题。

类目直接使用本公司TikTok本土/跨境类目库，不增加类目开放开关。策略保存实际类目库ID、商品类目和属性、公开产品模板、售价、库存、COD、标题要求及数量。

- 每个链接5–9个素材SKU，每次10–50个独立商品组；素材按模板尺码展开。
- 单个XLSX最多4994数据行，第7–5000行；超限拒绝，不拆分或减少数量。
- 同链接素材、源SKU、主图URL不重复；跨链接允许复用。Seller SKU保持素材SKU加尺码，不追加任务编号。
- 库存默认999，本土店支持COD时默认Y。
- 一个用户最多1个未完成任务；提交有幂等键，相同请求返回原任务。

提交时保存策略、用户/代理、模板导出版本、类目原XLSX及解析选项、候选素材版本/URL/SKU和随机种子；不保存图片字节。原类目记录删除不会破坏快照。

素材下架、模板取消公开、类目库删除及模板修改，只影响新提交任务。已提交任务继续使用快照。

货盘草稿独立于内部ProductDraft，不修改内部发布和导出计数。

## 生成、图片和标题

后台顺序：领取租约 → 组织草稿 → 初始标题 → 数据库解析图片地址 → 写 Excel → 上传并验证 R2 → 原子提交完成与使用统计。

图片统一按实际文件内容转存或复用 R2；默认跳过重复素材，用户可明确创建新 SKU，仍共用同一文件。不再保存图片状态，不在上架、提交、创建草稿或导出阶段访问图片源。缺少文件登记时阻止最终导出，不自动换图。

图片上传、外链导入、历史整理与部署顺序见 [图片文件去重说明](image-file-dedup.md)。内部 TikTok、Shopee 和货盘共用数据库地址解析，文件保存和内容校验在上传或导入时完成。

货盘 DeepSeek 配置仅设置 API Key，凭据按公司加密存储，与商品草稿使用的个人密钥独立；配置入口沿用 HubStudio、妙手管理的状态条与弹窗样式。标题生成及连接测试固定使用 deepseek-flash 并关闭思考，不接受模型修改，旧配置中的模型名称不再参与调用。首版使用文本商品事实。每链接最多4次调用，次数在请求前持久化。失败使用管理员审核的英文基础标题。AI 标题和兜底标题均追加链接序号后缀，例如 Printed Long Sleeve Nursing Maxi Dress - L01；序号从 1 开始，至少两位，超过 99 时保留完整数字。同一任务内标题保持唯一，不再通过后缀区分不同任务。

AI标题同样保留编号，最终标题25–255字符、单行、规范化后同表不重复。不改变SKU。

## 队列、文件与统计

使用MySQL队列及独立supply-worker。短事务按公司协调，任务执行版本隔离旧Worker。续租独立于网络/写表，重启只接管过期租约，不重置运行中任务或重试次数。

| 配置 | 默认 |
| --- | --- |
| SUPPLY_WORKER_CONCURRENCY | 4 |
| SUPPLY_COMPANY_CONCURRENCY | 2 |
| SUPPLY_TITLE_CONCURRENCY | 3 |
| SUPPLY_HEARTBEAT_SECONDS | 15 |
| SUPPLY_LEASE_SECONDS | 90 |
| SUPPLY_FILE_RETENTION_DAYS | 7 |

前端每5秒查看真实阶段与进度。租约90秒是无续租后的接管门槛，不是任务时长限制。失败任务重新提交为新任务。

私有文件复用R2_HUB_EXPORT_BUCKET，货盘对象前缀supply-exports/，独立于Hub的hub-exports/。不可对货盘前缀套用Hub的7天删除规则。

R2上传首次加3次重试，复用同一Excel，不重复标题或图片检查。上传后验证实际字节的大小和SHA256，并在完成事务中再检查账号与执行权。文件通过后端鉴权下载，不提供永久公开链接，管理员代下载记录审计。新生成的文件默认保留7天，到期后清理文件，保留任务和审计；已有文件沿用生成时记录的到期时间。超过24小时且未被任务引用的孤立对象由每小时扫描清理。

取消任务释放待上传Excel数据库缓存。成功使用统计只计最终素材，记录用户、提交时代理、不同用户/任务数、链接出现次数、最近成功时间；失败和被替换素材不计成功。内部使用单独归属，下载次数独立记录。
